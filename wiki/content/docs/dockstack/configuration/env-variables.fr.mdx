---
title: Variables d'environnement
---

import { formatDescription } from "@/lib/format-description"
import { envVars } from "@/lib/shared"

Toute la configuration se fait via des variables d'environnement.

## Requises

<div class="relative overflow-auto prose-no-margin my-6">
  <table>
    <thead>
      <tr>
        <th>Variable</th>
        <th>Description</th>
      </tr>
    </thead>
    <tbody>
      {Object.entries(envVars)
        .filter(([, v]) => v.required)
        .map(([name, v]) => (
          <tr key={name}>
            <td>
              <code>{name}</code>
            </td>
            <td>{formatDescription(v.description)}</td>
          </tr>
        ))}
    </tbody>
  </table>
</div>

## Optionnelles

<div class="relative overflow-auto prose-no-margin my-6">
  <table>
    <thead>
      <tr>
        <th>Variable</th>
        <th>Défaut app</th>
        <th>Défaut Docker</th>
        <th>Description</th>
      </tr>
    </thead>
    <tbody>
      {Object.entries(envVars)
        .filter(([, v]) => !v.required)
        .map(([name, v]) => (
          <tr key={name}>
            <td>
              <code>{name}</code>
            </td>
            <td>{v.default ? <code>{v.default}</code> : "—"}</td>
            <td>
              {(v.dockerDefault ?? v.default) ? <code>{v.dockerDefault ?? v.default}</code> : "—"}
            </td>
            <td>{formatDescription(v.description)}</td>
          </tr>
        ))}
    </tbody>
  </table>
</div>

Voir [redeploy](/fr/docs/openapi/redeployAllRunningStacks) pour <EnvVar name="REDEPLOY_SKIP" /> et
[URLs de services auto-détectées](/fr/docs/dockstack/features/auto-detect-urls) pour <EnvVar name="AUTODETECT_URL_BASE_DOMAIN" />.

L'image Docker officielle (`ghcr.io/zareix/dockstack`) définit elle-même <EnvVar name="STACKS_DIR" />, <EnvVar name="DATABASE_PATH" /> et <EnvVar name="DOCKER_CONFIG_DIR_PATH" /> — correspondant aux chemins de volumes utilisés dans l'exemple d'[installation](/fr/docs/dockstack/installation). Ne les remplacez que si vous changez ces chemins de montage.
