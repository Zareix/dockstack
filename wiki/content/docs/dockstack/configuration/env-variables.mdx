---
title: Environment Variables
---

import { formatDescription } from "@/lib/format-description"
import { envVars } from "@/lib/shared"

All configuration is done through environment variables.

## Required

<div class="relative overflow-auto prose-no-margin my-6">
  <table>
    <thead>
      <tr>
        <th>Variable</th>
        <th>Description</th>
      </tr>
    </thead>
    <tbody>
      {Object.entries(envVars)
        .filter(([, v]) => v.required)
        .map(([name, v]) => (
          <tr key={name}>
            <td>
              <code>{name}</code>
            </td>
            <td>{formatDescription(v.description)}</td>
          </tr>
        ))}
    </tbody>
  </table>
</div>

## Optional

<div class="relative overflow-auto prose-no-margin my-6">
  <table>
    <thead>
      <tr>
        <th>Variable</th>
        <th>App default</th>
        <th>Docker default</th>
        <th>Description</th>
      </tr>
    </thead>
    <tbody>
      {Object.entries(envVars)
        .filter(([, v]) => !v.required)
        .map(([name, v]) => (
          <tr key={name}>
            <td>
              <code>{name}</code>
            </td>
            <td>{v.default ? <code>{v.default}</code> : "—"}</td>
            <td>
              {(v.dockerDefault ?? v.default) ? <code>{v.dockerDefault ?? v.default}</code> : "—"}
            </td>
            <td>{formatDescription(v.description)}</td>
          </tr>
        ))}
    </tbody>
  </table>
</div>

See [redeploy](/docs/openapi/redeployAllRunningStacks) for <EnvVar name="REDEPLOY_SKIP" /> and
[Auto-detected service URLs](/docs/features/auto-detected-urls) for <EnvVar name="AUTODETECT_URL_BASE_DOMAIN" />.

The official docker image (`ghcr.io/zareix/dockstack`) sets <EnvVar name="STACKS_DIR" />, <EnvVar name="DATABASE_PATH" />, and <EnvVar name="DOCKER_CONFIG_DIR_PATH" /> itself — matching the volume paths used in the [installation](/docs/installation) example. Override them only if you change those mount paths.
