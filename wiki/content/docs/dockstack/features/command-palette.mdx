---
title: Command palette
---

Press <kbd>Cmd</kbd>+<kbd>K</kbd> (macOS) or <kbd>Ctrl</kbd>+<kbd>K</kbd> (Windows/Linux) from any private page to open the command palette.

## What it searches

- Stacks — opens the stack page.
- Containers, images, volumes and networks — opens the resource page with the table filtered to the selected entry.
- Pages and settings — Stacks, Containers, Images, Volumes, Networks, Account and Security.

The palette only navigates; it does not run destructive actions.
