title: API
description: Redeploy webhook and other endpoints
---

API endpoints (except health check) require an [API key](/docs/configuration/authentication#api-keys) as a bearer token.

## List stacks

```sh
curl https://dockstack.example.com/api/stacks \
  -H "Authorization: Bearer <your-api-key>"
```

Returns each stack's name and status (`up`, `down`, `unknown`, ...).

## Redeploy

Pulls the latest images and restarts every stack that has at least one running service. Stopped stacks are left untouched — handy as a CI step or Git webhook after pushing new images.

```sh
curl -X POST https://dockstack.example.com/api/stacks/redeploy \
  -H "Authorization: Bearer <your-api-key>"
```

Skip specific stacks with the `REDEPLOY_SKIP` environment variable (comma-separated stack names).

## Health check

```sh
curl https://dockstack.example.com/api/health
```

No auth required. Returns `{ "status": "ok" }`.
